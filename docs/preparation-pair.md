# 수련 원본·배포 데이터 정리 기록

정리일은 2026-09-23이다. 이 문서는 초기 預備式 4동작 이전 후보를 보존하기 위한 기록이 아니라, 현재 eztaiji에서 무엇을 자료로 남기고 무엇을 해석으로 표시하는지 설명한다.

## 현재 범위

- 預備式: 확인된 시작 자세 + 2026-09-23 현장 지도에 근거한 1동작. 기존 4동작 후보는 제거했다.
- 太極起勢: 6동작.
- 攬雀尾: 21동작. 左掤 6동·右掤 5동·左履 2동·右擠 3동·雙按 5동으로 읽는다.
- 나머지 권가: 자료를 확인하는 중이며 현재 Dataset에 임의의 세부 동작을 만들지 않는다.

## 자료·해석·수련 메모

세 종류를 섞지 않는다.

1. **자료**는 접근해서 확인한 문헌·기록에서 직접 읽을 수 있는 내용이다. `basis: source`로 둔다.
2. **해석**은 자료에 적힌 관계를 좌표·신체 물리·음양·무술 맥락으로 풀어쓴 내용이다. `basis: inference` 또는 학습용 도해라면 `illustration`로 둔다.
3. **수련 메모**는 현장에서 사부님의 설명을 사용자가 기록한 내용이다. `basis: observation`으로 둔다.

확인하지 못한 값을 자료의 확정 사실로 만들지 않는다. 다만 개인 연습에 필요한 평면 좌표는 `basis: illustration`인 학습용 근사로 둘 수 있으며, 실측·원문 사실과 구분한다.

## 預備式 정리

초기에 존재했던 `p001-m01`~`p001-m04` 이전 후보, 그 결과 상태, `legacy-preparation` Source와 관련 해석은 삭제했다. 이후 2026-09-23 현장 설명에서 직접 확인되는 몸의 하강·손의 상대적 상승만으로 새로운 `p001-m01`을 구성했다.

시작 자세에서 확인되는 外八字, 右實左虛, 몸의 정렬과 팔의 자연스러운 하수는 자료로 보존한다. 발의 화면 위치는 시작 구조를 보기 위한 학습용 근사 좌표로 별도 보존하고, 세부 접촉값은 근거가 없으면 만들지 않는다.

2026-09-23 수련에서 기록한 “몸의 기준 높이가 내려가며 손이 상대적으로 올라가 보이는 관계”는 현재 預備式 1동작의 직접 설명이면서, 자세 전체에서 읽을 수 있는 원리·음양 해석에도 연결한다.

## 자세 사이의 연결

일반적으로 다음 자세의 시작은 직전 자세의 마지막 상태를 공유할 수 있다. 다만 預備式의 옛 번호 동작은 삭제했기 때문에 그 객체를 다시 살리지는 않는다.

太極起勢 시작에는 `explicitState`로 별도의 학습용 좌표 상태를 둔다. `(0,0) / (1,0)` 배치와 허실·C는 좌표판용 근사임을 명시한다. 1–6동작에서도 같은 평면 배치를 유지해 팔·관절 변화와 발의 평면 구조를 함께 볼 수 있게 한다. 攬雀尾는 太極起勢 6동작 종료 상태를 시작 상태로 참조한다.

## 날짜별 수련 메모

같은 날짜의 메모는 Source 하나로 합친다. 현재 2026-09-23 기록은 `sifu-2026-09-23` 하나다.

그날의 預備式, 太極起勢, 전신 경직 방지 설명을 서로 다른 Source로 쪼개지 않는다. 대신 각 Claim의 locator에 “預備式”, “太極起勢 1–3동작”, “관절 변화 가능성”처럼 관련 부분을 적어 어느 메모 대목을 쓰는지 구분한다.

## 배포 화면

- 현재 동작의 설명 위에 **자료** 또는 **해석**을 표시한다.
- 설명의 근거 종류를 `자료 기록`, `수련 메모`, `프로젝트 해석`, `학습용 근사`로 표시한다.
- 원리·음양·전투 가정 등 파생 설명은 **해석** 영역에 둔다.
- 하단의 **출처 · 수련 메모**에는 그 화면에서 실제로 참조한 Source만 보여준다.
- 좌표 상세는 `source / observation / inference / illustration` 근거 종류를 함께 보여준다. 학습용 좌표는 `학습용 근사`라고 표시한다.

## 검사 원칙

- 깨진 ID와 Source 참조를 거부한다.
- 첫 자세의 초기 상태는 명시적으로 존재해야 한다.
- 이후 자세는 직전 종료 상태를 참조하거나, 독립적인 학습 좌표가 필요하면 `explicitState`, 상태 자체가 없으면 `unregistered`로 둘 수 있다.
- 자세에는 번호 동작이 0개일 수 있다. 이는 그 자세가 ‘동작이 없다’는 뜻이 아니라 현재 세부 단계 자료를 제공하지 않는다는 뜻이다.
- 확인된 명시적 근거가 없는 Toe/Heel 배지는 만들지 않는다.
- 해석과 작성자용 메타데이터를 원자료 사실로 승격하지 않는다.

구조 검사가 통과해도 태극권 동작의 실제 정확성을 보증하지 않는다. 실제 수련에서는 사부님의 지도를 우선하고, 자료와 현장 설명이 다르면 차이를 기록한 뒤 다시 검토한다.

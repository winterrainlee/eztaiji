# 수련 원본·배포 데이터 정리 기록

최초 정리일은 2026-09-23이고, 預備式 4동작 원문 재대조는 2026-10-03에 진행했다. 이 문서는 eztaiji에서 자료·해석·수련 메모를 어떻게 구분하고, 삭제했던 預備式 4동작을 어떤 근거로 다시 복원했는지 기록한다.

## 현재 범위

- 預備式: 확인된 시작 자세 + 원문에서 다시 대조한 4동작. 1동작의 몸 하강·손의 상대적 상승은 2026-09-23 현장 지도도 함께 반영한다.
- 太極起勢: 6동작. 시작 상태는 預備式 4동작 종료 상태를 그대로 공유한다.
- 攬雀尾: 21동작. 左掤 6동·右掤 5동·左履 2동·右擠 3동·雙按 5동으로 읽는다.
- 나머지 권가: 자료를 확인하는 중이며 현재 Dataset에 임의의 세부 동작을 만들지 않는다.

## 자료·해석·수련 메모

세 종류를 섞지 않는다.

1. **자료**는 접근해서 확인한 문헌·기록에서 직접 읽을 수 있는 내용이다. `basis: source`로 둔다.
2. **해석**은 자료에 적힌 관계를 좌표·신체 물리·음양·무술 맥락으로 풀어쓴 내용이다. `basis: inference` 또는 학습용 도해라면 `illustration`로 둔다.
3. **수련 메모**는 현장에서 사부님의 설명을 사용자가 기록한 내용이다. `basis: observation`으로 둔다.

확인하지 못한 값을 자료의 확정 사실로 만들지 않는다. 개인 연습에 필요한 평면 좌표는 `basis: illustration`인 학습용 근사로 둘 수 있으나 실측·원문 사실과 구분한다.

## 預備式 4동작 재대조

초기에는 `p001-m01`~`p001-m04` 후보가 있었지만 당시에는 `legacy-preparation`에 기대는 추론이 많아 2026-09-23에 제거했다. 이후 현장에서 확인한 몸의 하강·손의 상대적 상승만으로 새 `p001-m01`을 구성했다.

2026-10-03에 Tsaifucius의 `預備勢─4動`과 `第一式: 預備式`을 다시 읽어 다음 흐름을 직접 확인했다.

1. 몸을 가볍게 낮추고 왼발 뒤꿈치를 들어 左虛右實을 만든다.
2. 왼발을 왼쪽으로 열어 어깨너비에 두고 발끝을 비스듬히 점지하며 두 손을 양옆으로 약 15도 연다.
3. 왼발을 바로 놓고 뒤꿈치를 내리며 중심을 왼발로 옮겨 左實右虛가 된다. 오른발은 아직 비스듬한 방향을 유지한다.
4. 오른발 끝을 안으로 돌려 두 발을 평행하게 맞추고, 어깨를 풀어 손목과 손을 아래로 가라앉힌다.

따라서 과거 `legacy-preparation` 객체를 되살리지 않고, 같은 ID를 원문 근거로 새로 작성해 4동작을 복원한다.

2동작의 발 위치는 원문 안에서도 `向左側橫開`와 `向左方稍前橫伸`처럼 표현이 조금 다르다. 그래서 화면 좌표는 왼쪽 어깨너비라는 주 구조만 보여주고, 작은 전후 오프셋을 숫자로 확정하지 않는다.

## 자세 사이의 연결

預備式 4동작 종료 상태는 두 발이 어깨너비로 평행하고 왼발이 實, 오른발이 虛인 상태다. 太極起勢는 바로 이 상태에서 이어진다. 따라서 太極起勢의 시작은 더 이상 별도의 `explicitState`를 만들지 않고 預備式 마지막 상태 `p001-m04-end`를 참조한다.

시작 화면은 직전 동작의 사건을 다시 재생하지 않는다. 같은 `stateId`를 공유하더라도 제목·설명·현재 동작 번호는 새 자세의 시작 문맥으로 표시한다.

## 날짜별 수련 메모

같은 날짜의 메모는 Source 하나로 합친다. 현재 2026-09-23 기록은 `sifu-2026-09-23` 하나다.

그날의 預備式, 太極起勢, 전신 경직 방지 설명을 서로 다른 Source로 쪼개지 않는다. 대신 각 Claim의 locator에 관련 부분을 적어 어느 메모 대목을 쓰는지 구분한다.

## 배포 화면

- 현재 동작의 설명 위에 **자료** 또는 **해석**을 표시한다.
- 설명의 근거 종류를 `자료 기록`, `수련 메모`, `프로젝트 해석`, `학습용 근사`로 표시한다.
- 원리·음양·전투 가정 등 파생 설명은 **해석** 영역에 둔다.
- 하단의 **출처 · 수련 메모**에는 그 화면에서 실제로 참조한 Source만 보여준다.
- 좌표 상세는 `source / observation / inference / illustration` 근거 종류를 함께 보여준다.
- 발 좌표·여덟 방향 섹터는 학습용 근사이며, 원문이 정확한 거리를 고정하지 않는 부분은 수치로 과장하지 않는다.

## 검사 원칙

- 깨진 ID와 Source 참조를 거부한다.
- 첫 자세의 초기 상태는 명시적으로 존재해야 한다.
- 이후 자세는 가능한 경우 직전 종료 상태를 참조하고, 독립 좌표가 필요한 경우에만 `explicitState`를 사용한다.
- 확인된 명시적 근거가 없는 Toe/Heel 배지는 만들지 않는다.
- 해석과 작성자용 메타데이터를 원자료 사실로 승격하지 않는다.
- 같은 원문 안에 미세한 표현 차이가 있으면 임의의 정확한 수치로 화해시키지 않는다.

구조 검사가 통과해도 태극권 동작의 실제 정확성을 보증하지 않는다. 실제 수련에서는 사부님의 지도를 우선하고, 자료와 현장 설명이 다르면 차이를 기록한 뒤 다시 검토한다.

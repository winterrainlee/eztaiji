# eztaiji 동작 좌표계 원칙

- 문서 버전: 1.2
- 용도: 태극권 초식의 발 위치와 몸 회전을 기록하고 웹앱에서 시각화하기 위한 공통 규칙
- 표기 성격: 易簡太極拳의 공식 용어 체계가 아니라, 동작의 공간 관계를 이해하기 위해 만든 프로젝트 학습 표기법

## 1. 목적과 적용 범위

이 좌표계는 자세의 모양만 외우지 않고, 발이 공간을 어떻게 점유하는지, 체중과 중심이 어떻게 옮겨지는지, 몸이 어느 방향으로 도는지를 한 화면에서 읽기 위해 사용한다. 손과 팔은 발·중심·몸 회전과 함께 기록하되, 손 모양만으로 동작을 설명하지 않는다.

실제 자세와 동작 순서는 사부님의 지도와 해당 易簡太極拳 자료를 우선한다. 웹앱은 관찰한 내용과 해석을 구분해 저장한다. 영상이나 지도에서 확인되지 않은 중간 동작을 사실처럼 보간하지 않는다.

## 2. 좌표 기준

### 2.1 보는 방향과 축

좌표는 수련자를 위에서 내려다본 평면으로 읽는다. 좌우는 관찰자의 좌우가 아니라 수련자 자신의 좌우다.

| 표기 | 의미 |
| --- | --- |
| `+x` | 수련자의 오른쪽 |
| `−x` | 수련자의 왼쪽 |
| `+y` | 太極起勢가 끝났을 때 바라보는 정면 |
| `−y` | 그 정면에서 뒤쪽 |

기존 설명에서 쓴 東·北은 축을 기억하기 위한 이름일 뿐, 실제 나침반 방향을 뜻하지 않는다.

### 2.2 원점과 기준 자세

기본 원점은 太極起勢가 끝난 순간으로 고정한다. 한 초식 안에서 원점을 임의로 옮기지 않는다. 별도 동작을 독립적으로 분석하려고 기준을 다시 잡을 때는 그 사실을 기록한다.

| 발 | 기준 좌표 | 허실 |
| --- | --- | --- |
| 왼발 | `(0, 0)` | `● 實` |
| 오른발 | `(1, 0)` | `○ 虛` |

발 좌표는 발바닥 접촉면의 가운데를 가리킨다. 발끝 위치와 발의 방향은 좌표점과 분리해서 기록한다.

### 2.3 격자 단위

좌표는 실제 센티미터나 사람마다 다른 보폭을 재는 값이 아니라, 동작 사이의 상대적인 거리와 변화를 비교하기 위한 정규화 단위다. 기준 자세의 좌우 간격을 시각적 한 칸으로 두고, 동작에서 분명한 한 걸음은 보통 `1`만큼 이동한 것으로 기록한다. 작은 발 정렬이나 각도 조정은 필요할 때 `0.2`~`0.4` 같은 소수 좌표로 표시한다. 이 수치는 관찰을 돕는 근삿값이며, 실측값처럼 해석하지 않는다.

발 위치는 연속 좌표를 허용한다. 실제 이동이 불확실하면 억지로 격자점에 맞추지 말고 근삿값 또는 미확인으로 남긴다.

## 3. 발의 허실과 중심

| 기호 | 의미 |
| --- | --- |
| `●` | 實. 현재 몸을 주로 받치며 뿌리 역할을 하는 발 |
| `○` | 虛. 체중이 충분히 빠져 이동하거나 방향을 바꾸기 쉬운 발 |
| `C` | 몸의 질량중심을 바닥에 투영한 대략적인 위치 |

`●/○`는 체중을 백분율로 나눈 표시가 아니다. 두 발에 체중이 나뉘는 전환 중에는 어느 발이 주된 지지인지 표시하고, `C`의 이동이나 `移重中` 메모로 과정을 설명한다. `C`는 정밀한 생체역학 측정값이 아니므로, 방향만 확인되는 경우 좌·우·앞·뒤 또는 이동 화살표만 적어도 된다.

동작을 읽을 때는 발의 위치와 허실, `C`의 위치와 이동, 몸 방향, 팔의 역할을 함께 본다. 앞에 놓인 발이 곧바로 實이 되는 것은 아니다. 발이 새 자리에 닿아도 중심이 옮겨오기 전까지는 虛일 수 있다.

### 3.1 발 접촉 표기

확인된 접촉 정보는 해당 발 좌표 옆에 표시한다. `Toe`는 발끝 접촉, `Heel`은 뒤꿈치 접촉을 뜻한다. `Heel ↑`는 뒤꿈치 들기, `Heel ↓`는 뒤꿈치 내리기를 뜻하며, 뒤꿈치부터 착지하는 동작과 구분한다. 여기서 ↑/↓는 높이 변화이며 평면상의 이동 방향이 아니다.

접촉 표시는 원자료에 접촉 부위나 들기·내리기가 명시된 경우에만 기록하며, 출처와 해당 동작을 함께 저장한다. 허실이나 발끝 방향만으로 접촉 부위·회전축을 추정하지 않는다. 근거가 없으면 해당 표시는 생략한다.

## 4. 몸 방향과 회전

몸 방향 `B`(Body)는 기본적으로 골반·허리의 회전에 이끌리는 몸통의 현재 방향을 뜻한다. 골반과 상체가 크게 따로 움직이는 동작은 필요한 경우 둘을 나눠 적는다. 몸 방향은 발끝 방향과 별개다.

기준 정면 `+y`를 `0°`로 둔다. 수련자의 오른쪽 `+x` 방향으로 도는 회전을 양수로 기록한다. 방향만 간단히 표시할 때는 화살표를 쓴다.

| 화살표 | 각도 | 화살표 | 각도 |
| --- | ---: | --- | ---: |
| `↑` | `0°` | | `↓` | `180°` |
| `↗` | `45°` | | `↙` | `225°` (또는 `−135°`) |
| `→` | `90°` | | `←` | `270°` (또는 `−90°`) |
| `↘` | `135°` | | `↖` | `315°` (또는 `−45°`) |

`B`는 현재 방향이고 `ΔB`는 바로 앞 기록에서 얼마나 회전했는지를 뜻한다. 방향이 대략적으로만 보이면 화살표만 쓰고, 영상이나 지도에서 각도를 충분히 확인할 수 있을 때만 도 단위 값을 쓴다. 발끝 방향이 필요한 동작은 왼발·오른발의 발끝 방향을 각각 선택 항목으로 기록한다.

회전은 무릎을 비트는 동작으로 설명하지 않는다. 고관절·골반·허리가 회전을 이끌고 무릎은 발끝 방향을 따라가게 본다. 지지 중인 발을 억지로 비틀지 않으며, 발을 축으로 쓰는지 발을 먼저 비우는지는 동작별로 구분해 기록한다.

## 5. 동작을 시간 순서로 기록하는 원칙

좌표 한 장은 한 순간의 상태를 나타낸다. 허실 전환, 발 이동, 중심 이동, 몸 회전이 바뀌는 지점은 별도 프레임으로 나눈다. 기본 판독 순서는 다음과 같다.

1. 현재 주된 지지발과 虛인 발을 확인한다.
2. 발을 옮기거나 돌리기 전에 필요한 만큼 그 발의 체중을 덜어낸다.
3. 발의 새 위치를 기록한다. 발이 닿은 것과 체중이 실린 것을 구분한다.
4. `C`가 이동하고 지지 역할이 바뀌는 과정을 기록한다.
5. 골반·허리 중심의 `B`와 `ΔB`를 적고, 그 결과로 나타나는 팔의 역할을 덧붙인다.

이 순서는 동작을 분석하기 위한 기본 질문이지, 모든 초식이 같은 순서로 움직인다는 뜻은 아니다. 실제 순서는 확인한 권가 자료와 사부님의 설명에 맞춘다.

### 5.1 시작 상태와 자세 간 연결

각 자세에는 1동작에 들어가기 직전의 **시작 상태**를 둔다. 시작 상태는 실제 권가에 새 동작을 추가하는 것이 아니라, 첫 동작이 무엇에서 무엇으로 변하는지 읽기 위한 기준 프레임이다. 따라서 동작 번호를 붙이지 않고 UI에서도 `0동작`이 아니라 `시작 상태`라고 표시한다.

일반적인 자세에서는 **이전 자세의 마지막 동작이 끝난 상태와 다음 자세의 시작 상태가 같은 물리적 상태**다. 데이터에서는 같은 상태를 두 번 독립적으로 해석하지 않고, 다음 자세의 시작 상태가 이전 자세의 마지막 결과 상태를 참조하는 것을 원칙으로 한다. 다음 자세에서는 그 상태를 새로운 움직임의 출발점이라는 맥락에서 다시 보여줄 수 있다.

첫 자세인 預備式에는 참조할 이전 자세가 없으므로 `권가 시작 전 상태`를 별도의 초기 상태로 둔다. 이 초기 상태의 발 위치·허실·중심·몸 방향은 실제 수련이나 자료에서 확인된 범위만 기록하고, 확인되지 않은 값은 임의로 채우지 않는다.

시간 순서로 보면 한 자세는 다음처럼 읽는다.

`시작 상태 → 1동작 → 1동작 결과 상태 → 2동작 → … → 마지막 동작 결과 상태`

웹앱에서는 각 번호의 동작 화면이 해당 동작을 마친 결과 상태를 좌표판에 보여주고, 설명은 바로 앞 상태에서 그 결과 상태로 어떻게 변하는지를 다룬다. 따라서 1동작의 출발점은 항상 그 자세의 시작 상태다.

이 규칙은 64자세·365동작의 기존 동작 수를 바꾸지 않는다. 시작 상태는 탐색과 비교를 위한 보조 프레임이다.

## 6. 한 프레임의 기록 형식

| 항목 | 기록 내용 |
| --- | --- |
| 초식·프레임 | 초식 이름과 순서를 구분하는 식별자 |
| 왼발·오른발 | 각각의 `(x, y)` 위치와 `●/○` 상태 |
| 발끝 방향 | 필요할 때만 발별 방향을 추가 |
| `C` | 중심의 대략적 위치 또는 이동 방향; 모르면 미기록 |
| `B`, `ΔB` | 몸의 현재 방향과 직전 프레임 대비 회전 |
| 손·팔 | 몸의 구조와 공간 이동에서 맡는 역할 |
| 원리 메모 | 비움, 지지, 흘림, 회전, 전진 등 해석 |
| 근거·확실도 | 사부님 설명, 영상 시점, 직접 관찰 등과 관찰/추론/예시 구분 |

웹앱에서는 발의 좌표와 허실, 중심, 몸 방향을 서로 독립된 값으로 저장한다. `C`나 각도를 확인하지 못한 경우 임의의 값을 만들지 않고 비워 둔다. 해석이 포함된 프레임은 `관찰`, `추론`, `설명용 예시` 중 하나로 표시하고 근거를 남긴다.

## 7. 기준 예시

아래는 특정 초식의 재현이 아니라 좌표 읽는 법을 보여주는 설명용 예시다.

| 순간 | 왼발 | 오른발 | 중심 `C` | 몸 방향 `B` |
| --- | --- | --- | --- | --- |
| 太極起勢 종료 | `(0,0) ●` | `(1,0) ○` | 왼발 쪽에 가까움 | `↑` (`0°`) |
| 빈 왼발을 정면에 놓음 | `(0,1) ○` | `(1,0) ●` | 오른발 쪽에 남음 | `↑` (`0°`) |
| 중심을 왼발 쪽으로 옮김 | `(0,1) ●` | `(1,0) ○` | 왼발 쪽으로 이동 | 실제 회전이 없으면 `↑` |

이 예시는 발이 먼저 새 공간에 놓일 수 있고, 그 뒤 중심이 이동해야 지지 역할이 바뀐다는 점을 나타낸다.

## 8. 웹앱 표시·데이터 원칙

- 화면은 수련자 기준의 위쪽 시점으로 그린다. 좌우 반전 여부를 혼동시키지 않는다.
- 발의 위치, 발끝 방향, 몸 방향, 중심은 서로 다른 시각 요소로 표시한다.
- 모르는 값과 아직 확인하지 않은 구간을 추정값으로 채우지 않는다.
- 실제 동작을 확인한 프레임과 학습을 돕는 설명용 그림을 구분한다.
- 화살표와 좌표는 자세를 이해하기 위한 요약이다. 사부님의 실제 지도와 발 간격·각도를 대체하지 않는다.

## 9. 원칙 요약

태극권 동작은 `허실 변화 → 발의 공간 이동 → 중심 이동 → 지지 전환`의 관계와 `골반·허리 회전 → 몸 방향 변화 → 팔의 역할`을 함께 보며 해석한다. 좌표는 이 관계를 비교하고 설명하기 위한 공통 언어다. 좌표 숫자 자체를 정답으로 삼지 않는다.

이 문서는 eztaiji 웹앱을 위한 좌표 표기 규칙의 첫 버전이다. 초식 데이터를 추가하면서 실제 지도·영상과 맞지 않는 규칙이 발견되면 근거를 남기고 버전을 갱신한다.

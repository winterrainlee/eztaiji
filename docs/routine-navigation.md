# 단 → 자세 → 동작 내비게이션

프로젝트 자료 `태극권 목차 파악.txt`에서 확인한 易簡太極拳 6단 체계를 기본으로 사용한다. 원자료의 온라인 강의 목차는 전체 자세·동작 수를 담고 있지 않아 아래 자료로 보완했다.

## 자료

- 프로젝트 목차: 화롄 易簡太極拳 太極拳學, https://www.hualienyjtaichi.org.tw/taichi_science.asp (현재 직접 조회 실패; 프로젝트에 저장된 목차 참고)
- 중화국제태극권연맹: https://wtccf.blogspot.com/2022/03/blog-post_36.html (1·2·4단을 선택한 全民版. 이 축약판의 번호를 전체 64자세 번호로 사용하지 않는다.)
- 신베이시 易簡太極拳협회: https://www.yjtc-ntpc.com/教授內容/ (6단 체계, 365동, 단의 종결 자세 설명)
- Tsaifucius Tai Chi Notes: https://tsaitaiji.blogspot.com/2024/03/1-64.html (64자세의 순서와 개별 동작 수. 지도자의 수련 기록으로 보충한 자료이며 화롄의 세부 지도와의 대조는 추후 필요하다.)

## 목차 범위

| 단 | 자세 번호 | 자세 수 | 동작 수 |
| --- | --- | --- | --- |
| 1 | 1–13 | 13 | 73 |
| 2 | 14–21 | 8 | 59 |
| 3 | 22–32 | 11 | 63 |
| 4 | 33–44 | 12 | 61 |
| 5 | 45–55 | 11 | 69 |
| 6 | 56–64 | 9 | 40 |
| 합계 | 1–64 | 64 | 365 |

단 경계는 프로젝트의 6단 체계, 협회가 설명한 종결 자세, 전체 64자세 순서와 全民版의 단 구분을 대조해 구성했다. 이름은 보충 자료 표기를 기본으로 보존하고 太極起勢만 기존 프로젝트 표기와 통일했다. 다른 자료의 이체자·오탈자 가능성을 남겨 두며 향후 사부님의 권보와 대조한다.

## 동작 선택

상단에서는 단과 자세만 선택한다. 적용하면 해당 자세의 **시작 상태**를 먼저 보여주고, 하단의 다음 버튼으로 1동작부터 순서대로 이동한다. 시작 상태는 공식 동작 수에는 포함하지 않지만, 화면에서는 자세 이름과 함께 `0동작`으로 표시해 현재 위치를 분명히 한다.

일반적인 자세의 시작 상태는 이전 자세의 마지막 동작이 끝난 상태를 참조한다. 자료 객체를 직접 이어받기 어렵지만 연습용 좌표 기준이 필요한 경우에는 `explicitState`로 별도의 학습용 시작 상태를 둘 수 있다. 현재 太極起勢가 이 방식이며, 攬雀尾는 太極起勢 6동작 종료 상태를 참조한다.

제3자세 攬雀尾의 21동은 左掤 6동, 右掤 5동, 左履 2동, 右擠 3동, 雙按 5동으로 표시한다. 이 묶음은 설명 영역에서 안내하며 별도 자세나 새로운 단으로 세지 않는다. 시작 상태 역시 21동에 포함되지 않는다.

단을 직접 변경하면 선택한 단의 첫 자세 시작 상태로, 자세를 직접 변경하면 해당 자세의 시작 상태로 이동한다. 순차 탐색에서는 `시작 상태 → 1동작 → … → 마지막 동작 → 다음 자세의 시작 상태` 순으로 이동한다. 시작 상태에서 이전을 누르면 이전 자세의 마지막 동작으로 돌아간다. 전체 처음과 끝에서는 이동할 수 없는 방향의 버튼을 비활성화한다.

## 도해와 설명의 등록 상태

현재 預備式은 확인된 시작 자세와 수련 메모를 제공하고 시작 위치는 학습용 근사 좌표로 표시한다. 太極起勢 6동작도 발·허실·C의 평면 좌표를 학습용 도식으로 유지하며, 동작 자료·해석과 구분한다. 攬雀尾 21동작은 확인한 자료와 프로젝트 해석을 함께 제공한다.

## 검증

현재 배포 화면은 자세를 고르면 `자세 이름 · 0동작`에서 시작한다. 번호 동작이 없는 預備式에서는 다음 버튼이 곧바로 太極起勢 시작 상태로 이동한다. 太極起勢 0동작에는 별도의 학습용 좌표 상태를 사용한다.

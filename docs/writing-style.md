# eztaiji 문체 가이드

eztaiji의 사용자에게 보이는 한국어 설명은 이 문서를 기본 기준으로 작성한다.

## 1. 대상 독자

기본 독자는 **태극권을 막 배우기 시작한 한국인 고등학생**으로 잡는다.

- 태극권 수업을 몇 번 들어 `實·虛`, `중심 이동` 같은 말을 들어봤을 수는 있다.
- 그러나 태극권 용어와 중국어 표현을 이미 안다고 가정하지 않는다.
- 쉬운 말로 설명하되, 개념 자체를 단순화하거나 정확성을 희생하지 않는다.
- 학습자가 동작을 외우는 것보다 **몸에서 무엇이 일어나는지 이해하도록 돕는 것**을 우선한다.

## 2. 기본 문체

사용자 화면에서는 친근하고 자연스러운 반말을 쓴다.

- 한 문장에는 되도록 한 가지 내용만 담는다.
- 한 문단은 2~3문장을 기본으로 한다.
- 짧고 구체적인 동사를 쓴다.
- 보고서나 연구 노트 같은 문장보다, 옆에서 동작을 설명해 주는 문장을 쓴다.
- 쉬운 우리말이 있으면 어려운 한자어나 번역투를 먼저 쓰지 않는다.

예:

> 오른발의 체중을 덜어. 그러면 오른발을 가볍게 돌릴 수 있어.

피한다:

> 우측 하지의 허실 전환을 통해 회전 가능한 상태를 형성한다.

## 3. 페이지 정보 구조와 설명 순서

한 동작 화면의 정보는 서로 다른 질문에 답한다. 같은 사실을 문장으로 반복하기보다 각 영역의 책임을 고정한다.

| 영역 | 답하는 질문 | 책임 |
| --- | --- | --- |
| **What · 지금 할 일** | 이번 동작에서 무엇이 달라지는가? | 동작 제목이 핵심 변화를 한 줄로 말한다. 별도의 동작 요약 문단으로 같은 내용을 다시 쓰지 않는다. |
| **Where · 그림** | 동작 뒤 몸은 어디에 있는가? | 결과 상태의 발 위치·허실·B·C·필요한 방향을 보여준다. 변화 과정은 설명하지 않는다. |
| **How · 움직이는 법** | 그 변화를 어떻게 만드는가? | 순서, 중심 이동, 몸통과 팔다리의 연결, 原空位·原體位 같은 수행 방법을 설명한다. 동작 제목을 첫 문장에서 그대로 재진술하지 않는다. |
| **Check · 확인할 것** | 제대로 했는지 무엇으로 확인하는가? | 틀리기 쉬운 점과 몸으로 확인할 기준을 한 범주에 둔다. 개수만으로 ‘기본/추가’로 나누지 않는다. |
| **Why · 원리와 의미** | 왜 이렇게 움직이는가? | 해당 동작의 인과, 음양 관계, 연결된 공통원리, 무술적 가정을 구분해 보여준다. |
| **Evidence · 근거** | 이 설명은 어디에서 왔는가? | 현재 화면에 실제로 표시한 주장과 상태의 근거만 보여준다. |

같은 정보가 서로 다른 매체로 반복되는 것은 허용한다. 예를 들어 `왼발 ●實`을 문장과 좌표판에서 함께 보여주는 것은 읽기와 시각 확인이라는 기능이 다르다. 반대로 `지금 할 일`과 `움직이는 법`이 같은 문장을 말만 바꿔 반복하는 것은 피한다.

해석의 범위도 화면 책임과 맞춘다. 자세 전체에 적용되는 `Interpretation(scope: posture)`은 해당 자세의 **0동작**에서 읽고, 개별 `motion` 해석은 그 동작 화면에서만 읽는다. 여러 동작에 반복되는 `GlobalPrinciple`은 본문을 복제하지 않고 연결된 동작에서 이름과 짧은 요약만 보여준 뒤 공통원리 화면으로 연결한다.

동작 설명 자체는 가능하면 다음 순서를 따른다.

1. 지금 몸에서 무엇이 변하는지 동작 제목으로 확인한다.
2. 그림에서 결과 상태와 허실을 본다.
3. **움직이는 법**에서 체중·중심과 몸통·팔·다리가 이어지는 과정을 읽는다.
4. **확인할 것**으로 실제 자세를 점검한다.
5. 필요한 경우에만 **원리와 의미**를 펼쳐 왜 그렇게 움직이는지 본다.

학습자에게 필요한 행동과 감각을 먼저 말하고, 근거나 제작 과정은 뒤로 보낸다.

예:

> 왼발이 체중을 받는 동안 오른발은 가볍게 둬. 그래서 오른발을 다음 위치로 옮길 수 있어.

`허실 전환`, `운동 사슬` 같은 용어부터 시작하지 않는다.

## 4. 태극권 용어

태극권 고유 용어는 없애지 않는다. 대신 처음 나올 때 바로 뜻을 붙인다.

예:

- **實(실)**: 체중을 주로 받치고 있는 쪽
- **虛(허)**: 체중을 덜어 가볍게 둔 쪽
- **권가(拳架)**: 정해진 순서대로 이어서 연습하는 태극권 동작

한자를 보여주는 것이 학습에 도움이 되는 용어는 `實`, `虛`, `舒筋十二式`, `易簡太極拳`처럼 원문을 함께 쓴다.

같은 문단에서 이미 설명한 용어를 계속 다시 풀이하지 않는다.

## 5. 추상어는 몸의 움직임으로 풀어 쓴다

다음과 같은 표현은 단독으로 쓰지 않는다.

- 허실의 전환
- 중심 이동
- 연결된 움직임
- 회전
- 이완
- 음양

가능하면 실제 몸에서 일어나는 변화와 함께 설명한다.

예:

> 한쪽 발에 있던 체중이 다른 발로 넘어가면서 허와 실이 바뀌어.

> 허리만 먼저 돌리지 않아. 다리에서 시작한 변화가 몸통과 팔까지 이어져.

## 6. 원리와 동작을 연결한다

원리 설명은 추상적인 정의로 끝내지 않는다.

가능하면 현재 동작에서 그 원리가 무엇을 가능하게 하는지 설명한다.

예:

> 오른발이 虛가 되면 발에 체중이 거의 남지 않아. 그래서 몸 전체를 흔들지 않고 발끝 방향을 바꿀 수 있어.

학습자가 읽고 나서 **“그래서 이 동작을 이렇게 하는구나”**라고 이해할 수 있어야 한다.

## 7. 정보의 성격을 구분한다

원자료와 eztaiji의 해석을 섞어 쓰지 않는다.

화면의 표기는 다음 기준을 따른다.

### 자료

교육자료, 권보, 현장 기록 등에서 직접 확인한 내용.

### 프로젝트 해석

원자료를 바탕으로 동작을 이해하기 쉽게 정리한 설명. 좌표, 허실, 중심 이동을 학습용으로 해석한 내용이 포함될 수 있다.

### 가정

무술적인 상황이나 상대와의 관계를 이해하기 위해 제시하는 하나의 가능한 예시.

확인되지 않은 내용을 자연스럽게 보이게 하려고 채워 넣지 않는다.

## 8. 좌표와 도식 설명

좌표와 각도는 실측값처럼 표현하지 않는다.

- 발 위치는 움직임을 비교하기 위한 학습용 근사값이다.
- `● 實 / ○ 虛`는 체중 관계를 빠르게 보기 위한 표현이다.
- `B`는 현재 몸이 향하는 방향이다.
- 발의 화살표는 발끝 방향을 나타낸다.

정확한 수치보다 **어디에서 어디로 이동하는지, 어느 쪽이 받치고 어느 쪽이 자유로운지**를 이해시키는 것을 우선한다.

## 9. 소개·도움말은 짧게 쓴다

소개 페이지와 도움말은 프로젝트 제작 기록이 아니다.

사용자가 먼저 알고 싶은 질문에 답한다.

1. 이 사이트는 무엇을 도와주는가?
2. 어디서 시작하면 되는가?
3. 그림과 기호는 어떻게 읽는가?
4. 설명은 어떤 근거로 나뉘는가?

촬영 날짜, 전사 과정, 데이터 입력 현황, 세부 통계, 자료 대조 기록은 학습에 직접 필요하지 않으면 본문에서 빼고 참고 자료나 개발 문서로 보낸다.

## 10. 피해야 할 문체

### 용어를 설명하지 않고 겹쳐 쓰기

피한다:

> 허실의 전환과 중심 이동, 신체 연결을 통해 권가의 구조를 이해한다.

권장:

> 어느 발에 체중이 실리는지 먼저 봐. 그다음 중심이 어디로 움직이고, 그 변화가 몸통과 팔까지 어떻게 이어지는지 살펴봐.

### 제작자 관점으로 먼저 설명하기

피한다:

> 원문에서 중심 이동이 확인되는 단계에만 좌표 데이터를 입력했다.

사용자에게 필요한 경우:

> 좌표 그림은 위치와 중심 이동을 확인하는 데 필요한 동작에서 보여줘.

제작 과정 자체가 필요하면 개발 문서에 기록한다.

### 불필요하게 조심스러운 장문

정확성 때문에 한 문장 안에 예외와 단서를 모두 넣지 않는다. 핵심 설명을 먼저 쓰고, 필요한 주의사항은 별도 문장으로 분리한다.

## 11. 작성 전 확인

사용자에게 보이는 설명을 추가하거나 고칠 때 다음을 확인한다.

- 한국인 고등학생이 처음 읽어도 문장 뜻을 바로 알 수 있는가?
- 태극권을 이미 아는 사람만 이해할 표현이 남아 있지 않은가?
- 한 문장에 개념을 너무 많이 넣지 않았는가?
- 지금 몸에서 무엇이 일어나는지가 먼저 보이는가?
- 원자료와 프로젝트 해석을 구분했는가?
- 제작 기록이 학습 설명보다 앞에 나오지 않는가?
- 모바일 화면에서 너무 긴 문단이 되지 않는가?

## 12. 최종 기준

eztaiji의 설명은 **쉽게 읽히되 얕지 않아야 한다.**

전문용어를 많이 쓰는 것이 정확한 설명은 아니다. 학습자가 발, 중심, 몸통, 팔의 관계를 실제 움직임으로 떠올릴 수 있다면 좋은 설명이다.

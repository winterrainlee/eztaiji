# 모바일 학습 화면

## 목적

태극권에서 몸이 움직이는 원리를 이해하고, 자세를 스스로 점검하며 연습하도록 돕는다.

## 모바일 배치

1. 상단에는 학습 주제와 자료 성격을 표시한다.
2. 좌표 영역은 화면 위쪽에 유지한다. 발 위치·허실·중심 C·몸 방향 H를 함께 표시한다. 처음 정면을 기준으로 격자축을 고정한다.
3. 아래 설명 영역은 독립적으로 스크롤한다. 동작 지시 → 움직임의 원리 → 내 자세 확인 순서로 읽는다.
4. 하단에는 단계 선택과 이전·다음 버튼을 고정한다. 단계 변경 시 그림과 설명을 함께 갱신하고 설명의 처음으로 돌아온다.

태블릿과 넓은 화면에서는 좌표판과 설명을 좌우로 배치한다. 색상 외에도 채운 원·빈 원과 좌우 글자를 사용한다. 버튼은 키보드로 조작할 수 있고 단계 변경을 보조 기술에 알린다.

## 현재 구현 범위

`index.html`을 브라우저에서 열면 실행된다. 설치나 외부 통신이 필요 없는 단일 HTML 프로토타입이다.

현재 네 단계는 좌표계와 화면을 설명하기 위한 예시다. 특정 易簡太極拳 초식의 검증된 동작 데이터가 아니다. 몸 회전과 중심 위치는 예시이며 실제 수련 자료에서 확인한 값으로 교체해야 한다.

평면도에서 알 수 없는 무릎 굽힘·척추 정렬·어깨 긴장은 설명 영역의 자세 확인 항목으로 다룬다. 실제 몸을 촬영하거나 측정해 자세를 판정하는 기능은 없다.

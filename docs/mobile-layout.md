# 모바일 연습 화면

## 화면 배분

연습 중에는 상단 한 줄(48px), 고정 좌표판(보통 180~220px), 나머지 높이를 채우는 독립 스크롤 설명, 하단 한 줄(56px + 안전 영역)을 사용한다. 사용 가능 높이 640px에서 안전 영역을 제외하면 상단 48px, 좌표판 200px, 설명 336px, 하단 56px가 목표다. 480px 이하의 낮은 화면에서는 좌표판을 135px로 축소한다.

큰 로고·소개·중복 제목·단계 버튼 줄은 제거했다. 좌표판의 숫자 정보는 ‘상세’ 대화상자에서 확인한다. 태블릿과 데스크톱에서는 좌표판과 설명을 좌우로 배치한다.

## 복수 해석의 시각적 구분

하나의 설명 범주 안에 해석이 둘 이상 있을 때는 별도 카드로 쪼개지 않고 같은 범주 안에 둔다. 예를 들어 한 동작에 `虛 ↔ 實`과 `몸의 내려감 ↔ 손의 상대적 올라감`이 동시에 있으면 둘 다 **「여기서의 음양」** 안에서 읽는다.

다만 모바일에서는 단순 공백만으로 해석 경계가 흐려질 수 있으므로, 각 해석을 하나의 시각적 묶음으로 보고 **두 번째 묶음부터 위쪽에 얇은 점선과 충분한 세로 여백을 둔다.** 첫 번째 묶음 위와 마지막 묶음 아래에는 불필요한 구분선을 넣지 않는다. 현재 기준은 약 `18–20px`의 묶음 간격과 `1px dashed` 구분선이다.

구분선은 새로운 의미 범주를 뜻하지 않는다. 같은 음양 범주 안에서 서로 다른 관계를 읽기 쉽게 나누는 장치다. 따라서 기본적으로 `해석 1`, `해석 2` 같은 번호를 붙이지 않는다. 관계 자체에 자연스러운 이름이 있을 때만 그 이름을 사용한다. 해석이 하나뿐이면 구분선을 표시하지 않는다.

자료의 근거·관찰·프로젝트 해석 여부는 시각적 묶음과 별개의 정보다. 구분선을 넣었다고 각 해석의 확실도나 전통적 지위가 같아지는 것은 아니다.

## 공통 원리 표시

권가 전체에 걸쳐 반복되는 수련 원리는 소개 페이지에서 정의하고, 연습 화면에서는 현재 동작이 그 원리를 실제로 보여줄 때만 짧게 다시 표시한다. 같은 설명을 동작마다 복제하지 않고 `principleIds`로 공통 원리를 참조한다.

공통 원리는 `왜 이렇게 움직일까?` 뒤, `여기서의 음양` 앞에 놓는다. 카드에는 원리 이름과 한 줄 요약을 보여주고, 자세한 설명은 소개 페이지의 해당 원리로 연결한다. 공통 원리가 연결되지 않은 동작에서는 빈 카드나 자리표시자를 만들지 않는다.

## 탐색

상단 현재 단·자세를 누르면 단과 자세만 선택하는 패널이 아래에서 열린다. ‘이 자세 시작’을 누르면 선택한 자세의 1동작으로 이동한다. 하단의 현재 동작은 읽기 전용이며 이전·다음 버튼으로 이동한다. 상단의 별도 ‘소개’ 링크는 about.html을 연다. 닫기·Esc·배경 터치는 변경을 취소한다. 모달은 native dialog로 초점 이동과 배경 입력 차단을 제공한다.

하단 동작 표시는 `1동작`, `2동작`처럼 표기한다. 攬雀尾 내부 묶음은 설명 영역에서 별도로 안내한다. 이전·다음은 자세와 단 경계를 넘어간다.

## 예비식 4동작

이전의 네 단계 예시는 왼발을 앞으로 내딛는 가상 움직임이어서 폐기했다. 1단 제1자세 預備式에 다음 자료 기반의 4동작을 연결한다.

1. 오른다리 지지, 왼발 뒤꿈치를 들어 비우기.
2. 빈 왼발을 왼쪽 어깨너비로 열고 발끝 접촉.
3. 왼발을 정렬하고 뒤꿈치를 내리며 왼다리로 지지 전환.
4. 왼다리 지지를 유지하며 오른발 끝을 안쪽으로 정렬.

근거: 프로젝트의 예비식 연습 기록 및 https://tsaitaiji.blogspot.com/2024/03/1-64.html 의 預備勢/預備式 4動. 본문을 복사하지 않고 학습 지시·원리·자기 점검으로 정리했다.

발 끝의 짧은 화살표와 몸 방향 B를 구분한다. 좌표 원점은 기존 규칙의 太極起勢 종료 왼발이다. 예비식 첫 프레임의 왼발 x≈0.65와 중심 위치는 화면용 근사값이다. 발 회전 중 실제 접촉점 이동은 단순화하며 발끝 각도 역시 실측값으로 표시하지 않는다. 도해는 사부님의 실연을 대체하지 않는다.

## 구현 및 확인

index.html과 catalog.js를 같은 폴더에서 사용한다. 예비식은 처음부터 도해를 표시하고, 다른 자세의 미등록 도해는 준비 중 상태로 표시한다. 선택 취소·적용, 하위 선택 초기화, 자세 경계 이동, 예비식 허실과 발끝 정렬, 동작 표기를 실행 검증했다.

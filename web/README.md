# 화면 코드

이 폴더는 사람이 편집하는 HTML·스타일·브라우저 코드·정적 자산의 자리다. 발 좌표, 수련 설명, 음양·전투 가정, 권가 목차를 화면 코드 안에 별도 원본으로 저장하지 않는다.

이행 후 빌드는 허용된 화면 파일과 수련 원본에서 생성한 배포 데이터를 합쳐 `dist/`를 만든다. 브라우저는 정리된 배포 데이터를 읽고 화면 선택·그리기·스크롤·최소 오류 안내를 담당한다.

현재는 폴더의 역할만 확정한 단계다. 운영 화면은 아직 루트 `index.html`, `about.html`, `catalog.js`를 사용하며 이 폴더로 복사하거나 옮기지 않았다. 새 경로가 검증되기 전에 기존 파일을 삭제하지 않는다.

파일 이동, 직접 열기 호환성, Pages 전환은 [검사·변환·배포 경로](../docs/data-pipeline.md)의 이행 순서에 따라 확인한다. 이 README는 배포할 화면 자산에 포함하지 않는다.

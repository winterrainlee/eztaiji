# 수련 원본

이 폴더는 사람이 검토하고 교정하는 eztaiji 수련 데이터의 기준이다. 배포 결과물을 역으로 복사해 원본으로 사용하지 않는다.

기준 파일은 `datasets/yijian.json`이다. 현재 預備式은 확인된 시작 자세와 2026-09-23 수련 메모만 남기고, 예전에 옮겨 둔 4동작 후보와 `legacy-preparation` 자료는 제거했다. 太極起勢 6동작과 攬雀尾 21동작은 접근 가능한 기록을 바탕으로 저장하며, 원자료에서 읽은 내용과 프로젝트 해석을 구분한다.

같은 날의 현장 수련 기록은 Source 하나로 묶고, 실제로 어느 설명을 근거로 삼았는지는 각 Claim의 `locator`로 구분한다. 좌표판은 수련 흐름을 읽기 위한 학습용 도식을 허용하되 `basis: illustration`로 명확히 표시한다. 자료에서 확인한 사실과 학습용 좌표를 같은 것으로 취급하지 않는다.

상태·동작·해석·근거는 [데이터 모델](../docs/data-model.md)을 따른다. 현재 실행 가능한 지원 범위 이름은 여전히 `preparation-pilot`이지만, 데이터 범위는 預備式·太極起勢·攬雀尾까지 확장되어 있다. `notes/`에는 공개 가능한 작업 메모만 두고 자동으로 기준 Dataset에 채택하지 않는다.

이 저장소는 공개되어 있으므로 사이트 배포에서 제외되는 원본도 비공개가 아니다. 공개하면 안 되는 메모는 저장소 바깥에 둔다.

`python scripts/check_preparation_pair.py --emit`은 원본과 변환 결과를 검사하고 `.build/preparation/`에 읽기용 결과를 생성한다. 생성물을 직접 편집하지 않는다. 실제 사이트는 현재 루트 HTML과 `published/` 자산을 사용한다.

현재 정리 기준은 [수련 원본·배포 데이터 정리 기록](../docs/preparation-pair.md), 전체 경로 설계는 [검사·변환·배포 경로](../docs/data-pipeline.md)를 따른다.

# 수련 원본

이 폴더는 사람이 검토하고 교정하는 수련 데이터의 자리다. 배포 결과물을 역으로 복사해 원본으로 사용하지 않는다.

기준 파일은 `datasets/yijian.json`이다. 현재는 예비식 시작 상태와 4동작만 포함한 부분 Dataset이며, 이전 웹앱의 설명·도해를 옮긴 **이전 후보**다. 외부 권보 원문 재대조와 사부님 확인이 끝난 상태는 아니다.

상태·동작·해석·근거는 [데이터 모델](../docs/data-model.md)을 따른다. 현재 실행 가능한 지원 범위는 `preparation-pilot`으로 제한하며, 전체 모델을 구현한 것으로 보지 않는다. `notes/`에는 공개 가능한 작업 메모만 두고 자동으로 원본에 채택하지 않는다.

이 저장소는 공개되어 있으므로 사이트 배포에서 제외되는 원본도 비공개가 아니다. 공개하면 안 되는 메모는 저장소 바깥에 둔다.

`python scripts/check_preparation_pair.py --emit`은 원본과 변환 결과를 검사하고 `.build/preparation/`에 읽기용 결과를 생성한다. Node와 개발용 Python jsonschema가 필요하다. 생성물을 직접 편집하지 않는다.

현재 운영 화면은 기존 루트 `index.html`의 데이터를 사용한다. 원본 파일 수정이 운영 화면에 반영되는 단계는 아니다. 자세한 검증 범위와 미확인 항목은 [예비식 원본·배포 데이터 쌍](../docs/preparation-pair.md), 목표 구조와 전환 순서는 [검사·변환·배포 경로](../docs/data-pipeline.md)를 따른다.

# 수련 원본

이 폴더는 사람이 검토하고 교정하는 수련 데이터의 자리다. 배포 결과물을 역으로 복사해 원본으로 사용하지 않는다.

목표 기준 파일은 `datasets/yijian.json`이다. 상태·동작·해석·근거는 [데이터 모델](../docs/data-model.md)을 따른다. `notes/`에는 공개 가능한 작업 메모만 두며, 빌드는 메모를 자동 채택하지 않는다.

이 저장소는 공개되어 있으므로 사이트 배포에서 제외되는 원본도 비공개가 아니다. 공개하면 안 되는 메모는 저장소 바깥에 둔다.

현재는 폴더의 역할만 확정한 단계다. 실제 Dataset 파일과 변환기는 아직 없고, 예비식 데이터는 기존 루트 `index.html`에 남아 있다. 자세한 목표 구조와 전환 순서는 [검사·변환·배포 경로](../docs/data-pipeline.md)를 따른다.

# eztaiji

태극권 동작의 원리를 이해하고 자세를 점검하기 위한 학습용 웹앱입니다.

[웹앱 열기](https://winterrainlee.github.io/eztaiji/)

상단의 단·자세를 누르면 단 → 자세 → 동작을 선택할 수 있습니다. 좌표판은 고정되고 아래 설명만 스크롤합니다. 하단의 이전·현재 동작·다음으로 이동합니다.

1단 預備式 4동작의 학습용 근사 도해와 설명을 제공합니다. 나머지 자세의 도해는 준비 중입니다. 발 좌표·중심·발끝 각도는 실측값이 아닙니다.

로컬에서는 index.html과 catalog.js를 같은 폴더에 두고 HTML을 브라우저에서 엽니다. GitHub Pages는 main 브랜치 루트 폴더를 사용합니다.

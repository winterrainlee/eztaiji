# eztaiji

태극권 동작의 원리를 이해하고 자세를 점검하기 위한 학습용 웹앱입니다.

[웹앱 열기](https://winterrainlee.github.io/eztaiji/)

## 탐색

상단에서 단 → 자세 → 동작을 선택합니다. 상위 항목을 바꾸면 하위 목록이 갱신되며, 이전·다음 버튼으로 자세와 단을 넘어 이동할 수 있습니다. 실제 동작의 도해와 설명은 검증 후 추가할 예정입니다. 기존 설명용 그림은 ‘좌표 예시 보기’에서 열 수 있습니다.

로컬에서는 `index.html`과 `catalog.js`를 같은 폴더에 두고 HTML을 브라우저에서 엽니다. 배포는 GitHub Pages의 main 브랜치 루트 폴더를 사용합니다.
